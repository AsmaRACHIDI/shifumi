# Shifumi

Reconnaissance de gestes pierre-feuille-ciseaux par vision par ordinateur,
avec une application web pour jouer contre l'IA via la webcam.

## Statut

En cours de développement.

## Installation

```bash
python -m venv .venv
.venv\Scripts\activate      # Windows
pip install -e . -r requirements-dev.txt
```

## Tests

```bash
pytest
```
